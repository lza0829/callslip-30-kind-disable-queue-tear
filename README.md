# 叫号条（Callslip）

银行网点柜面叫号：取号入队 → 叫号推进 → 过号回收/重叫 → 当日队列封口。

- 前端 http://127.0.0.1:6400
- API http://127.0.0.1:11400
- `docker compose up -d --build`

## 种类停用口径（全局唯一，不得混用）

以「禁新发号留存量」为准。种类停用后：

- 新发号写口拒绝该种类（发号拒因条给出原因），号段游标冻结不推进；
- 存量等候/过号/在办**不冻结**，仍可被可办窗口叫号、重叫、办结、作废；
- 等候墙继续展示停用种类分栏（灰显标记），总览种类等候桶同口径计数；
- 启停写入 `kind_events`（含存量快照、游标与结局），停用结局可按事件重放；启停幂等，重复停用不重复记事件；
- 启停与取号/叫号等写口共用 `BEGIN IMMEDIATE` 事务串行化，并发停用与发号不留半截；
- 启停回执、发号拒因、叫号拒因、等候墙分栏、种类页、游标、总览等候桶同刷。

### 单一谓词与自证（假停用收口）

停用灯、发号闸、存量命运、事件重放四者必须同态，统一收敛在 `app/services/gate.py`：

- `发号闸 = 启用列 ∧ 营业日未封口 ∧ 有开放窗口`；`/取号` 写口与探针 `/业务种类/{id}/发号闸`
  同因同文，停用灯亮则写口必拒；
- `存量命运 = 存量号牌不冻结`（等候/过号可叫、在办可办结），`存量冻结` 恒为 `False`；
- 启停写口写后自证：启用列、发号闸、存量命运三者若不一致即抛错**整笔回滚**，禁止只改停用标签；
- 总览 `发号闸`、`/业务种类/停用审计`（灯/闸/存量/重放四线证据）与上述谓词同源；
  任一展示口与谓词不一致即判撕裂。

窗口收档与日切为独立需求，不在本口径范围。
