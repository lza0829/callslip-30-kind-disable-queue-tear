# 叫号条（Callslip）

银行网点柜面叫号：取号入队 → 叫号推进 → 过号回收/重叫 → 当日队列封口。

- 前端 http://127.0.0.1:6400
- API http://127.0.0.1:11400
- `docker compose up -d --build`

## 种类停用口径（全局唯一，不得混用）

以「禁新发号留存量」为准。种类停用后：

- 新发号写口拒绝该种类（发号拒因条给出原因），号段游标冻结不推进；
- 存量等候/过号/在办**不冻结**，仍可被可办窗口叫号、重叫、办结、作废；
- 等候墙继续展示停用种类分栏（灰显标记），总览种类等候桶同口径计数；
- 启停写入 `kind_events`（含存量快照与游标），停用结局可按事件重放；启停幂等，重复停用不重复记事件；
- 启停与取号/叫号等写口共用 `BEGIN IMMEDIATE` 事务串行化，并发停用与发号不留半截；
- 启停回执、发号拒因、叫号拒因、等候墙分栏、种类页、游标、总览等候桶同刷。

窗口收档与日切为独立需求，不在本口径范围。
